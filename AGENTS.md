# Repository instructions

- Read `README.md` completely before making changes.
- Treat `README.md` as the authoritative source for product scope,
  architecture, milestones, constraints, and acceptance criteria.
- Implement only the milestone explicitly requested by the user.

- Report commands actually executed, observed results, and anything not
  verified.
